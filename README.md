# Pocket Shop Preview

Build a simple mobile-friendly one-page website about Simple E-Commerce Website. Audience: People Buying Products. Main action: Seen Everything in that Website. Include a clear heading, a short introduction, an example section and one main button. Make that button work within the page where possible. Use clearly labelled placeholders for missing facts, images or destinations. Do not invent reviews or results. Keep this a preview; ask before publishing or connecting external services.
